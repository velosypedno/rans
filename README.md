
Необхідно мати пару rsa ключів. Аби забезпечити асиметричне шифрування. Для чого це треба?

Ми не будемо застосуввати асиметрчине шифрування до кожного окремого файлу, бо це неймовірна кліьксть операцій множення. Натомість ми будемо шифрувати звичайни симетричний ключ, яким і будемо шифрувати файли на системі жертви.

Перш за все нам необіхдно пара ключів:

```bash
ssh-keygen -t rsa -b 2048 -m PEM -f ./ransom_key -N ""
```

Маємо два ключі:

1. ransom_key  
2. ransom_key.pub


Обидва ми зашиваємо прямо в бінарники для шифрування та дешифрування
